A friend of my mom mentioned how hard it can be to generate a certain Monthly Budget Report, for they mostly work with Excel files that need many VLOOKUPs to gather their data.

She asked for help, so I endeavored to replicate what their workbooks output while minimizing human input.

The current commit is my first attempt, peer-reviewed to ensure the output is correct. My mom and her friend suggested some refinements and additional requirements, so I will keep updating this repository. Hopefully gradual improvements of my coding habits will come through with each commit.

Full disclosure, this project made some use of AI, as this project required some modules that were far outside of my knowledge base at the time. I made sure to use it sparingly and that I understood the meaning of its proposed code.
